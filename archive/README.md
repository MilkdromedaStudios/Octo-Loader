# Archive

Things Octo no longer ships, kept for reference.

- **`npm/`**: an `npm install -g octo-launcher` package. It downloaded the
  newest `octo-launcher.jar` from the GitHub release, checked it against
  `checksums.txt`, and ran it with the installed Java or a downloaded
  Temurin 21. It was never published. Octo Launcher is installed with
  `OctoLauncher-Setup.exe` on Windows, or by running `octo-launcher.jar`.
